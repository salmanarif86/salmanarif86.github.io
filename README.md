# Sal Arif — personal website

A responsive, one-page personal website. Open `index.html` in a browser, or run `python3 build.py` to create a portable single-file version at `dist/sal-arif-website.html` with the portrait embedded. Google Fonts are optional; local fallback fonts are specified.
